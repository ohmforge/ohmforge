One workbench, from op-point to firmware

SPICE-class analog

A nodal solver for R, L, C, diodes, and sources — DC operating point plus transient, drawn as a braille scope.

MCU co-simulation

Co-simulate AVR, RP2040, STM32, and ESP32 firmware against the same nodes, so your code and your circuit share one clock.

AI copilot

Describe a change in plain English; the copilot edits the netlist, explains the operating point, and reviews your design.

Terminal + browser

The whole workbench is a single Rust binary — run it as a TUI, a CLI, or compiled to WebAssembly in this very page.

Prefer the terminal? Same engine, one binary.

# run the prefilled demo and print the scope
$ cargo run -p ohmforge --bin of -- demo
# open the full terminal UI
$ of tui
# let the AI copilot review your design
$ of review
