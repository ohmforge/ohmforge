# Getting Support

Thanks for using **ohmforge** — a fast, AI-assisted EE playground for the terminal. Here is where to go depending on what you need.

## I have a question or want to discuss an idea

Use **[GitHub Discussions](https://github.com/ohmforge/ohmforge/discussions)**. It is the best place for:

- "How do I …?" and usage questions,
- help modeling a circuit, board, or simulation,
- ideas and design proposals before they become a formal feature request,
- showing off what you built.

Before posting, a quick search of existing discussions and issues often finds an answer already.

## I found a bug

Open a **[bug report](https://github.com/ohmforge/ohmforge/issues/new/choose)**. A minimal reproduction — ideally a short `.eesh` script or netlist — helps us fix it fast. See the issue template for the details we ask for.

## I want to request a feature

Open a **[feature request](https://github.com/ohmforge/ohmforge/issues/new/choose)**. Describe the problem you are trying to solve first; a concrete use case is worth more than a proposed implementation.

## I found a security vulnerability

**Do not** open a public issue. Report it privately — see [`SECURITY.md`](SECURITY.md).

## Contributing

Want to help build ohmforge? See [`CONTRIBUTING.md`](CONTRIBUTING.md) (we use **DCO** sign-off — `git commit -s`) and [`GOVERNANCE.md`](GOVERNANCE.md).

## Support expectations

ohmforge is a community-maintained open-source project. There is no paid support tier or SLA; maintainers and contributors help on a best-effort basis. Please be patient and kind — our [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) applies everywhere.
